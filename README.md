This repository contains a program that writes a two-line explanation of one everyday thing for a 10-year-old. Here are the shipped two lines verbatim:

> An escalator is a metal zipper of stairs that pulls people upward between floors.
> This maps the interlocking steps to a zipper, but it leaves out that zippers are pulled by hand while the escalator is driven by electric motors.
